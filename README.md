# Fibonacci TDD Kata

A Python implementation of the Fibonacci sequence, built using Test-Driven Development (TDD) with the Red-Green-Refactor cycle.

## What is Fibonacci?

F(0) = 0, F(1) = 1, F(n) = F(n-1) + F(n-2) for n >= 2

## Tools

- uv — Python project and dependency manager
- pytest — testing framework
- marimo — interactive notebook
- ruff — linter

## How to run

    uv run pytest notebook.py
    uv run marimo edit notebook.py

## TDD workflow

- develop — signature, red, green, refactor, docs
- optimization — performance tests for large n
- main — stable merged version
